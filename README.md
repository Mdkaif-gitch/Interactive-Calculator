# Interactive Calculator

A clean, responsive calculator built using **HTML, CSS, and JavaScript**.

## Features
- Addition, subtraction, multiplication, and division
- Decimal number handling
- All Clear (AC) and backspace delete
- Keyboard support
- Interactive button feedback
- Responsive layout for mobile and desktop
- Division-by-zero error handling

## Run locally
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Use the on-screen buttons or keyboard.

## Keyboard shortcuts
| Key | Action |
|---|---|
| `0–9` | Enter numbers |
| `.` | Decimal point |
| `+ - * /` | Select operation |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete last digit |
| `Escape` | Clear all |

## Technologies
- HTML5
- CSS3
- JavaScript (DOM manipulation and event handling)

## Project purpose
Created as a beginner-friendly project to practice JavaScript functions, operators, event handling, and DOM manipulation.
